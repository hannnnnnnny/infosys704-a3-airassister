## 1. 我们解决什么问题

Excel 原主题是 **Disrupt Self-services apps**，覆盖航变后的重订、退款、住宿等服务。AirAssist 选择其中的**退款案件准备与分流**作为第一版切片：让旅客提交完整申请，让审核人员看见缺项、证据和责任，并让旅客查询同一份最新记录。

目前形成的闭环是：**提交 → 补充检查与备注 → 标准或专家分流 → 本地交接 → 进度与收据同步**。A3 是四人小组作业；本次承接的是已提供的一位成员的个人 A1/A2 退款提案，另外三位成员的 A2 未被复核，也没有把这份个人 A2 写成此前的小组共同成果。SAP API 只部分匹配，所以按 **Option 2** 说明调整。它不取消真实机票、不决定真实退款资格、不批准退款、不付款；重订和住宿未实现。

实际评分以 **A3 V3、五项评分标准、Hint 和课程更新**为依据。此前 A2 的评分要求可用于检查论证连续性和展示质量，不会自动变成新的 A3 必交材料或时间规则；课程说明允许沿用一位成员的方案及模型。

1. 解压[AirAssist_A3_V1_4.zip](../A3_App_V1/AirAssist_A3_V1_4.zip)。Mac安装Python 3.10+，在`AirAssist_V1`目录打开终端，运行`sh start.command`；浏览器打开`http://127.0.0.1:8789/?view=journey`，保留终端。实际Mac仍需运行排练。当前开发预览使用`http://127.0.0.1:8791/`；解压包启动脚本默认8789，按该电脑运行输出打开。
2. 用 `NZ7K2H / Taylor` 提交，使用示例邮箱，保存生成的 `AF-` 编号；用同一邮箱查进度。
3. Staff review 显示缺项；填写明确的演示检查参考和备注，保存后交接。重开再勾选专家审核，保存并交接；核对 Track 与下载收据。
4. SAP 另机默认未配置，显示未连接属于真实状态。按 [README](../A3_App_V1/README.txt) 复制 `.env.example` 为 `.env`，填写**个人** API Hub key，明确设置 `AIRASSIST_SAP_MODE=live`，然后重启服务。查询 `60000002`；查询 `9999999999` 检查明确失败。不要在录屏、PPT 或共享文件展示 key。
